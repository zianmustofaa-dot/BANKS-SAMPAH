1. Analisis Sistem Informasi

1.1 Latar Belakang

Bank sampah adalah tempat warga menyetorkan sampah daur ulang (plastik, kertas, logam, kaca, elektronik) dan menukarnya dengan saldo uang. Sistem pencatatan manual di buku yang dilakukan petugas bank sampah sering menimbulkan permasalahan: salah hitung nilai setoran, saldo nasabah sulit dilacak, rekap bulanan memakan waktu, serta harga jenis sampah yang berubah menyebabkan riwayat transaksi lama tidak konsisten. Sistem informasi Bank Sampah Digital dibangun berbasis database terpusat dengan DBMS MySQL agar data nasabah, petugas, harga, setoran, dan penarikan saldo terekam secara rapi, konsisten, dan mudah direkap.

1.2 Tujuan

  1. Mencatat data master: nasabah, petugas, kategori sampah, dan jenis sampah beserta harga per kilogram.
  2. Mencatat setiap transaksi setoran sampah (siapa nasabahnya, kapan, petugas pencatat, jenis apa saja, berapa kg).
  3. Mencatat setiap transaksi penarikan saldo nasabah.
  4. Menghasilkan rekapitulasi: saldo tiap nasabah, total berat per kategori, nasabah teraktif, dan kinerja petugas.

1.3 Kebutuhan Data

KebutuhanData yang dikelola
Data masternasabah, petugas, kategori sampah, jenis sampah + harga/kg
Transaksi setortanggal, nasabah, petugas, daftar jenis sampah, berat, harga saat setor
Transaksi tariktanggal, nasabah, petugas, jumlah penarikan
Laporansaldo nasabah, berat per kategori, top nasabah, transaksi per petugas

1.4 Keputusan Desain

  • Harga snapshot. harga_satuan disimpan di tabel detail_setoran (bukan hanya memakai kolom harga_per_kg di jenis_sampah) agar nilai setoran lama tetap benar walaupun harga jenis sampah berubah dari waktu ke waktu.
  • Saldo dihitung, tidak disimpan. Saldo nasabah tidak dibuat kolom tersendiri; saldo dihitung dari total setoran dikurangi total penarikan sehingga tidak terjadi data ganda (redundansi) dan selalu konsisten.

4. Implementasi Database (SQL DDL)

4.1 Kode DDL (file 01_ddl.sql)

CREATE DATABASE bank_sampah_digital; USE bank_sampah_digital; CREATE TABLE kategori_sampah ( id_kategori INT PRIMARY KEY AUTO_INCREMENT, nama_kategori VARCHAR(50) NOT NULL, deskripsi VARCHAR(150) ); CREATE TABLE jenis_sampah ( id_jenis INT PRIMARY KEY AUTO_INCREMENT, id_kategori INT NOT NULL, nama_jenis VARCHAR(80) NOT NULL, harga_per_kg DECIMAL(10,2) NOT NULL, FOREIGN KEY (id_kategori) REFERENCES kategori_sampah(id_kategori) ); CREATE TABLE nasabah ( id_nasabah INT PRIMARY KEY AUTO_INCREMENT, nama VARCHAR(100) NOT NULL, alamat VARCHAR(200), no_hp VARCHAR(15), tgl_daftar DATE NOT NULL ); CREATE TABLE petugas ( id_petugas INT PRIMARY KEY AUTO_INCREMENT, nama_petugas VARCHAR(100) NOT NULL, jabatan VARCHAR(50), no_hp VARCHAR(15) ); CREATE TABLE setoran ( id_setoran INT PRIMARY KEY AUTO_INCREMENT, id_nasabah INT NOT NULL, id_petugas INT NOT NULL, tgl_setoran DATE NOT NULL, catatan VARCHAR(150), FOREIGN KEY (id_nasabah) REFERENCES nasabah(id_nasabah), FOREIGN KEY (id_petugas) REFERENCES petugas(id_petugas) ); CREATE TABLE detail_setoran ( id_detail INT PRIMARY KEY AUTO_INCREMENT, id_setoran INT NOT NULL, id_jenis INT NOT NULL, berat_kg DECIMAL(8,2) NOT NULL, harga_satuan DECIMAL(10,2) NOT NULL, FOREIGN KEY (id_setoran) REFERENCES setoran(id_setoran), FOREIGN KEY (id_jenis) REFERENCES jenis_sampah(id_jenis) ); CREATE TABLE penarikan_saldo ( id_penarikan INT PRIMARY KEY AUTO_INCREMENT, id_nasabah INT NOT NULL, id_petugas INT NOT NULL, tgl_penarikan DATE NOT NULL, jumlah DECIMAL(12,2) NOT NULL, FOREIGN KEY (id_nasabah) REFERENCES nasabah(id_nasabah), FOREIGN KEY (id_petugas) REFERENCES petugas(id_petugas) );

Q9 — Saldo tiap nasabah (subquery + LEFT JOIN + COALESCE): setoran dikurangi penarikan

SELECT n.id_nasabah, n.nama, COALESCE(s.total_setor, 0) AS total_setor, COALESCE(t.total_tarik, 0) AS total_tarik, COALESCE(s.total_setor, 0) - COALESCE(t.total_tarik, 0) AS saldo FROM nasabah n LEFT JOIN ( SELECT st.id_nasabah, SUM(d.berat_kg * d.harga_satuan) AS total_setor FROM setoran st JOIN detail_setoran d ON st.id_setoran = d.id_setoran GROUP BY st.id_nasabah ) s ON n.id_nasabah = s.id_nasabah LEFT JOIN ( SELECT id_nasabah, SUM(jumlah) AS total_tarik FROM penarikan_saldo GROUP BY id_nasabah ) t ON n.id_nasabah = t.id_nasabah;
